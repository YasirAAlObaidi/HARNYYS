Acme's inventory manager uploads a stock sheet in the web app and asks the agent to update Al Ameen. This project allows writes, but only through the stock import tool, and only after the person who asked confirms a preview. The model never writes SQL itself.

Space plays or pauses. The arrow keys step through. Click the bar to jump; the gaps mark the four phases. If Al Ameen turns out to have its own import feature, step 22 would hand it an import file instead of writing rows directly. That hasn't been checked yet.
